## 接口和访问

GET /api/dig/overview：客户与商机；GET /api/dig/lifecycle：项目、里程碑、开票申请、历史开票。服务端使用字段白名单，避免获取银行账号、纳税信息、联系电话和附件原文。完整分页且按源记录ID去重，游标重复拒绝输出部分聚合；60秒缓存与进程内并发合并。单一下游故障单独标记，count=null，不伪装为0条。

访问仅允许 DIG_DATA_ACCESS=local 且本机URL、同站请求；未接企业SSO，不能直接发布为多用户生产服务。页面显示应用授权范围，不将申请人视作经营负责人。工作台和客户入口改用真实台账，原演示任务与规则不混入真实经营视图；既有准入和风险模块仍是独立旧实现，并未因此完成生产验收。
