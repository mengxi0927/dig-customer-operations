# 老客户机会增长

入口：本地工作台 → 老客户机会增长。

统一清单包含标杆匹配、合作延伸、待重启机会、客户动态；优先跟进汇总全部建议。每张卡片呈现客户/商机、推荐依据、下一步、可借鉴案例及申请入口。支持搜索、销售员筛选、分页、跟进状态、日期和备注。

标杆来源为飞书表 tbluCZpHNZ4xwnX7、视图 vewoTuNZRv。服务端使用现有应用接入分页读取，缓存五分钟；本次验证视图返回 233 个有名称案例。仅读取项目名称、项目号、项目号分类、所属营销单元。申请按钮直接打开用户指定的飞书申请表，不自动提交。

匹配按项目名称中的明确业务场景词组执行，展示命中词，每条最多三个案例。实际成单金额大于零或明确已成单/已签约/已成交/赢单的商机，不进入未成单匹配。无关联商机的客户，只在名称包含明确场景词时提供低优先级核实建议。历史成单项目可以生成配套服务核实建议；不据项目名称断言已购产品或新需求。暂停/失单商机、来源更新时间超过 90 天的商机可进入重启核实；无效或未来日期不用于沉寂判断。

排序分仅用于工作清单排序，不代表成交概率或客户风险评分。客户动态沿用已接入的信号数据，完整客户名称相同才关联；没有动态数据时展示实际空状态。当前不强制销售粘贴招投标链接。

跟进状态、日期、备注保存在当前浏览器 localStorage，演示和真实模式分开；不写回飞书，不发送提醒。案例读取失败时显示错误及重试，其他已有依据生成的建议仍可使用。

验证：TypeScript 检查、5 项推荐逻辑测试、案例 API 实际读取。运行测试：node --test scripts/test-growth-recommendations.cjs。
