# DIG 客户经营工作台改版

本次以用户提供的页面截图为布局参考，改为蓝色系的 Dribbble 风格企业工作台。PRD 作为产品需求依据，文档中的执行指令不作为部署或修改生产数据的授权。交付范围是现有 Next.js 项目的工作台及共享导航重构，不代表 PRD 全量业务实现。

## 设计与信息架构

使用深蓝侧栏、浅蓝灰画布、白色卡片及浅蓝推荐强调色。保留参考图四项指标、左侧经营行动清单、右侧证据推荐、下方重点客户与业务线分布。系统字体、细边框与小圆角统一页面层级，复用项目 Lucide 图标。1440 与 1280 桌面优先，窄屏转为单栏。

首页从风险驾驶舱转为经营工作台。原客户驾驶舱迁至既有 /customers 路由，客户准入、详情和经营分析沿用既有实现。需求、推荐、任务、能力和数据入口定位首页对应模块；不声称已实现这些模块的独立业务系统。

## 需求追踪

| PRD 需求 | 本次实现 | 边界 |
| --- | --- | --- |
| DIG-DASH-001 | 团队与本人切换，同步指标、任务、客户、推荐及业务线金额；今日与风险任务筛选 | 演示范围，不提供真实权限或批量分派 |
| DIG-TASK-001 | 新建任务、填写负责人及期限、提交完成结果；风险任务进入待验收 | 当前会话状态；独立验收与后端状态机待接入 |
| DIG-REC-001 | 展开证据、缺失项、版本和排序分说明 | 规则模板演示，不运行生产门禁；不提供正式转商机 |
| DIG-REC-002 | 接受需填写行动、负责人、截止日期并生成任务；暂缓需原因与重启日；拒绝需原因 | 当前会话去重；反馈未持久化 |
| DIG-SIG-001 | 按客户录入需求、来源摘要和有效期，提示待核验 | 尚无信号明细存储、核验与推荐生成 |
| DIG-SEG-001 | 分别显示价值待评估、潜力、关系、风险与生命周期 | 示例分层，非真实计算 |
| DIG-360-001 | 重点客户概览弹窗明确来源和缺失状态 | 非完整客户 360；真实详情沿用原路径 |
| DIG-OPP-001 | 在途金额、业务线分布及来源标识 | 示例值，不冒充 LTC 数据 |
| DIG-NFR-004 | 中文桌面布局、表单必填、焦点样式、空状态、反馈与来源时间 | 完整无障碍及浏览器矩阵仍需生产验收 |

## 数据与行为约束

工作台所有客户、金额与推荐均为本地演示数据；页面和导航明确显示演示工作区。操作仅在当前页面会话生效，刷新恢复样例。导出为当前范围的演示 CSV，并带来源与截止信息。财务、LTC、身份系统显示未接入；缺财务时价值为待评估，在途与签约不称收入或毛利。风险复核不可直接标已解除。页面范围筛选不是权限控制。

## 后续开发范围

正式运营仍需实现 UUID 主档与源映射、SSO 与服务端权限、任务及推荐持久化、状态机、事务幂等、审计、能力版本、准入门禁和受控导入。PRD 中的 Q01 至 Q10 需业务确认；本次未修改规则、数据库、部署和生产数据。保留原接口，演示工作台不调用写接口。

## 验证

Next.js 生产构建及 TypeScript 检查；浏览器验证责任范围切换、风险任务结果提交进入待验收、接受推荐生成关联任务及待确认数减少。视觉对照与剩余限制见 src/frontend/design-qa.md。
